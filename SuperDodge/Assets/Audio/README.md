# Audio assets

Put `.mp3` files here.

Current default file names:

- `bgm_0_330.mp3`: looped from 0:00 to 3:30
- `bgm_331_530.mp3`: looped from 3:31 to 5:30
- `bgm_531_730.mp3`: looped from 5:31 to 7:30
- `bgm_731_end.mp3`: looped from 7:31 until game end
- `start.mp3`: game start
- `graze.mp3`: graze
- `hit.mp3`: player damaged
- `bomb.mp3`: bomb used
- `star.mp3`: star collected
- `clear.mp3`: game clear
- `game_over.mp3`: game over

Missing files are ignored, so the game still runs while assets are incomplete.
